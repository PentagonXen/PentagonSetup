# PentagonSetup

One command. Clean Windows.

## Run via PowerShell

Open PowerShell as Administrator, then run:

    irm https://raw.githubusercontent.com/PentagonXen/PentagonSetup/main/pentagon-setup.ps1 | iex

Or use the short link:

    irm tinyurl.com/pentagonsetup | iex

I run this on every Windows system I touch. Best run right after a fresh
Windows 10 or 11 install, before you pile on your own apps.

**Before you run:** don't touch your mouse or keyboard while the script is
running. A restart is highly recommended once the script finishes.
